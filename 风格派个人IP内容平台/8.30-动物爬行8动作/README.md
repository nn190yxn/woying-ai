## 项目简介

基于追光小牛「8.30 动物爬行·8个动作」现有图片和抖音文案制作的竖版短视频。采用已确认的 **B｜痛点→反转→清单** 方向：先解决“说一百遍坐直了有没有用”的认知，再进入 8 个动物动作清单，最后完成互动和品牌收口。

## 使用方式

1. 直接使用 `video/final.mp4` 发布或继续做平台内剪辑。
2. 需要改文案时，先更新 `storyboard-source.json`，再重新生成字幕和音频。
3. 发布时保留“落地屈膝缓冲”和“效果因人而异”等合规提示。
