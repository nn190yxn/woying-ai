# 设计稿｜B 痛点→反转→清单

## 目标

将现有 P1–P8 图片编排为一条适合抖音的 9:16 家长科普短视频，用“坐直提醒无效”的认知反转承接“动物爬行游戏化训练”，最终引导评论互动和关注追光小牛。

## 分镜

| 时间 | 图片 | 画面与字幕重点 |
|---|---|---|
| 0–5s | P2 | 孩子驼背，说一百遍“坐直了”，真的有用吗？ |
| 5–8s | P1 | 让他像小动物一样爬；他以为在玩，其实在练 |
| 8–16s | P3 | 小熊爬、螃蟹走；核心、手臂、肩背、侧向协调 |
| 16–24s | P4 | 青蛙跳、毛毛虫爬；落地屈膝缓冲 |
| 24–32s | P5 | 鳄鱼爬、猴子跳；全身协调、反应 |
| 32–38s | P6 | 鸭子走、小狗爬；腿力、平衡、幼幼版入门 |
| 38–42s | P7 | 感统基础动作；每天 10 分钟，选 4–5 个轮着玩 |
| 42–57s | P8 | 评论区互动、关注追光小牛、效果因人而异 |

## 动效

- 每张图片按原比例缩放到 1080×1440，置于 1080×1920 暖米色画布中央。
- 场景以轻微淡入淡出连接，避免主体变形、横向裁切和黑边。
- 字幕使用深蓝底部安全区，重点词用暖橙色表达。

## 声音

- Cherry 配音，`qwen3-tts-flash`。
- 旁白播放速度 1.08 倍，使总时长从约 61.33 秒压缩到约 56.77 秒。
- 背景音乐为低音量程序化轻快和弦，并对旁白自动 ducking。

## 合规

- 使用既有图片，不重新生成主体。
- 保留品牌水印。
- 青蛙跳提示落地屈膝缓冲。
- 结尾保留“效果因人而异”，不使用治疗、根治或极限承诺。
