# 测试验收手册

## 验收分层

我赢AI当前验收分为四层：

- 静态检查：确认后端语法和前端构建通过。
- 单元测试：验证关键纯函数和测试运行器行为。
- 接口冒烟：验证核心接口 HTTP 状态、统一协议和降级状态。
- 专业度深测：验证工具输出是否满足业务深度、行动建议和风险边界。

## 前端构建

前端使用 Vite，构建命令：

```bash
cd frontend
npm run build
```

构建通过代表 Vue 单文件组件、路由引用、依赖解析和静态资源打包通过。构建产物位于 `frontend/dist`。

## 后端语法检查

后端是 Node.js ESM 服务，重点文件可用 `node --check` 检查语法：

```bash
cd backend
node --check src/index.js
node --check src/routes/douyinAgents.js
node --check src/models/db.js
node --check src/models/mockDb.js
```

新增或修改路由时，应把对应路由文件加入检查范围。

## 后端测试脚本

`backend/package.json` 已定义以下测试和冒烟脚本：

```bash
cd backend
npm run test:douyin-diagnosis
npm run test:deep-runner
npm run smoke:core
npm run deep:test
```

### test:douyin-diagnosis

基于 `node:test` 验证抖音诊断 fallback：

- 低播放冷启动型和流量转化漏损型能被区分。
- `weakestDimension`、雷达分数和评分版本字段存在。
- 诊断依据包含行业参考线和评分轨迹。

### test:deep-runner

验证深测运行器自身行为，重点是输入协议、结构识别和状态分类。

### smoke:core

默认读取 `BASE_URL`，未设置时使用 `http://127.0.0.1:3000`。脚本会使用本地 `JWT_SECRET` 生成年费会员测试 token，覆盖健康检查、小红书、通用生成和毛利计算等核心接口。

可用环境变量：

- `BASE_URL`：目标服务地址。
- `SMOKE_TIMEOUT_MS`：单接口超时，默认 `30000`。
- `STRICT_DEGRADED=true`：将降级结果视为失败。

### deep:test

深度测试运行器读取测试 payload，支持按 group、code 或 endpointPrefix 过滤。常用环境变量：

- `BASE_URL`：目标服务地址，默认 `http://127.0.0.1:3000`。
- `TOKEN`：指定认证 token。
- `SMOKE_TIMEOUT_MS`：超时时间，默认 `60000`。
- `TEST_FILE`：测试用例文件，默认 `./scripts/test-payloads.json`。
- `REPORT_FILE`：报告输出路径。

运行器会识别 `PASS`、`FAIL`、`INPUT_MISMATCH`、`DEGRADED`、`STRUCTURE_COMPAT` 等状态。

## 线上冒烟

线上基础冒烟至少覆盖：

- `GET https://woyai.cn/api/health`
- 登录接口。
- 首页和核心前端 chunk 资源。
- 抖音 Hub 和本轮变更页面。
- 体检、15 天计划、脚本工具、复盘诊断。

抖音经营闭环新增接口冒烟至少覆盖：

- 生成并保存 15 天计划。
- 更新某一天任务状态。
- 读取已保存计划。
- 保存复盘记录。
- 读取最近复盘。
- 读取复盘记录列表。
- 读取复盘洞察。

## 专业度验收标准

生成类工具验收应同时看结构和内容质量。以下情况应判定为未达标：

- 仅返回 HTTP 200 但内容为空。
- 返回字段结构正确但摘要提示生成失败。
- 缺少行业基准、诊断依据、行动建议或风险边界。
- 输出只有泛化建议，无法指导老板下一步执行。
- 需要 AI 生成的高阶工具退化为纯规则模板。

达标输出应包含：

- 明确业务结论。
- 可追踪的数据或输入依据。
- 分优先级的行动建议。
- 适配行业、目标和当前阶段的具体策略。
- 风险说明和执行边界。
- 会员升级或定制服务引导文案。

## 抖音闭环专项验收

抖音经营闭环应按“体检 -> 作战计划 -> 执行 -> 复盘 -> 下一轮计划”的链路验收：

- 体检诊断输出 `radarData`、短板维度、参考线和建议。
- 15 天计划输出每日 `day`、`theme`、`shootingTask`、`scriptOutline`、`storeAction`、`expectedMetric`、`checkStatus`。
- 计划保存后刷新页面可恢复最近计划。
- 每日任务状态更新后再次读取仍保留状态。
- 复盘诊断能保存输入、结果、有效内容类型和下一步行动。
- 洞察接口能基于最近复盘聚合有效内容类型，并将建议带入下一轮计划。

## 文档与敏感信息检查

文档变更完成后执行空白检查：

```bash
git diff --check -- .monkeycode/docs
```

敏感信息检查应覆盖密钥类字段名和常见真实值格式。文档中允许出现变量名和占位符，严禁写入真实 API Key、数据库密码、JWT_SECRET、支付密钥和私钥内容。

## 发布前最低门槛

发布前最低门槛：

- 前端 `npm run build` 通过。
- 后端相关文件 `node --check` 通过。
- 核心冒烟无 HTTP 失败。
- 本轮新增接口冒烟通过。
- 生成类工具无非预期降级。
- 线上健康检查返回 `status: ok`。
- 已准备线上备份和回滚路径。
