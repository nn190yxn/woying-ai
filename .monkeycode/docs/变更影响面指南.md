# 变更影响面指南

## 使用方式

本指南用于判断修改某类功能时，需要同步检查哪些文件、接口、权限、测试和文档。优先遵循现有模块边界，小改动保持在对应链路内完成。

## 新增通用工具

通用工具应优先走 `/api/generate/:toolCode`。

需要检查：

- `backend/src/routes/generate.js`：工具执行入口、输入校验、输出结构。
- `backend/src/config/toolAccess.js`：工具所需会员等级。
- `backend/src/services/calculatorEngine.js`：计算器输入协议和计算逻辑。
- `backend/src/services/toolPayloadNormalizer.js`：测试和运行时输入归一化。
- `knowledge-base/`：Knowledge-AI 工具需要补齐知识库映射和内容。
- `frontend/src/views/tools/`：工具页面表单和结果展示。
- `frontend/src/api/index.js` 或 `frontend/src/api/tool.js`：前端调用是否复用现有封装。
- `backend/scripts/test-payloads.json`：深测 payload 是否覆盖新工具。

验证：

```bash
cd frontend
npm run build

cd ../backend
npm run deep:test
```

## 新增抖音专项工具

抖音专项工具应放在 `backend/src/routes/douyinAgents.js`，前端页面放在 `frontend/src/views/douyin/`。

需要检查：

- 专项路由是否使用 `checkAccess` 和 `requireLevel()`。
- 输出是否保留统一外层和领域内层结构。
- AI 输出是否需要 `responseFormat: { type: 'json_object' }`。
- fallback 是否返回页面可渲染结构。
- 页面是否通过 `@/api/request` 调用 `/douyin/*`。
- `frontend/src/router/index.js` 是否注册页面路由。
- `frontend/src/views/DouyinAgentHub.vue` 是否加入入口。
- 权限文案、升级引导和会员等级是否一致。

抖音经营闭环相关改动还要检查：

- `douyin_quick_plans` 保存计划结构。
- `douyin_review_records` 复盘记录结构。
- `/api/douyin/review-records/insights` 是否继续产出下一轮计划上下文。

验证：

```bash
cd backend
node --check src/routes/douyinAgents.js
npm run test:douyin-diagnosis

cd ../frontend
npm run build
```

## 新增小红书专项工具

需要检查：

- `backend/src/routes/xhsAgents.js`：接口、权限和 fallback。
- `frontend/src/views/xhs/`：页面表单和结果展示。
- `frontend/src/router/index.js`：`/xhs/*` 路由。
- `frontend/src/views/XhsAgentHub.vue`：工具矩阵入口。
- 知识库映射和专业输出格式。

小红书工具等级集中在路由内的 `requireLevel()` 调用，接口文档和路由映射文档应同步更新。

## 新增私域专项工具

需要检查：

- `backend/src/routes/privateAgents.js`：接口、权限和知识库读取。
- `frontend/src/views/private/`：页面表单和结果展示。
- `frontend/src/router/index.js`：`/private/*` 路由。
- `frontend/src/views/PrivateAgentHub.vue`：工具矩阵入口。
- 会员等级、升级文案和输出结构。

私域知识库摘要访问已收口到辅助函数，后续改动优先复用既有 helper。

## 修改会员等级或权限

需要同步检查：

- `frontend/src/constants/membership.js`：前端等级顺序、标签和访问判断。
- `backend/src/config/toolAccess.js`：通用工具等级。
- `backend/src/config/plans.js`：套餐价格、周期和名称。
- `backend/src/routes/douyinAgents.js`：抖音专项 `requireLevel()`。
- `backend/src/routes/xhsAgents.js`：小红书专项 `requireLevel()`。
- `backend/src/routes/privateAgents.js`：私域专项 `requireLevel()`。
- `frontend/src/views/Membership.vue`：会员页展示和购买入口。
- `frontend/src/router/index.js`：后台入口要求 `annual`。
- `.monkeycode/docs/专有概念/MembershipAndAccess.md`：文档同步。

验证重点：未登录、免费、初阶、进阶、高阶用户看到的入口和后端放行结果一致。

## 修改支付链路

需要检查：

- `backend/src/config/plans.js`：价格、周期和显示名称。
- `backend/src/routes/payment.js`：创建订单、回调签名、事务和会员有效期。
- `backend/src/utils/referral.js`：推荐佣金和奖励。
- `frontend/src/views/Membership.vue`：购买入口和支付状态展示。
- `miniapp/`：小程序支付入口。

验证重点：订单创建、回调幂等、会员有效期累加、推荐佣金不影响主支付流程。

## 修改登录或验证码

需要检查：

- `backend/src/routes/auth.js`：验证码、注册、登录和 JWT 签发。
- `backend/src/config/redis.js`：Redis 策略。
- `backend/src/middleware/auth.js`：JWT 校验和 guest mode。
- `frontend/src/views/Login.vue`、`frontend/src/views/Register.vue`：表单和错误提示。
- `frontend/src/api/request.js`：401 处理和 token 注入。

验证重点：验证码有效期、内测验证码、生产 JWT_SECRET、401 跳转和登录后会员等级写入。

## 修改数据库模型

需要检查：

- `backend/src/models/db.js`：真实 MySQL 初始化或连接逻辑。
- `backend/src/models/mockDb.js`：本地 mock 行为。
- 相关路由文件中的 SQL 查询。
- `.monkeycode/docs/数据模型.md`：字段和业务语义。
- 线上部署手册：新增表是否需要单独迁移或懒初始化。

验证重点：生产环境不落 mock、用户数据按 `user_id` 隔离、JSON 字段可序列化和反序列化。

## 修改前端请求封装

需要检查：

- `frontend/src/api/request.js`：baseURL、timeout、token 注入、401 行为。
- `frontend/src/api/index.js`：通用生成、配额、历史和本地事件上报。
- `frontend/src/api/tool.js`：工具列表、运行、生成和历史。
- 所有直接使用 `fetch()` 或 `axios` 的页面。

验证重点：登录后请求携带 token，错误提示经过 normalized 处理，页面不会因响应外层变化崩溃。

## 修改知识库或 AI 输出

需要检查：

- `backend/src/services/ai.js`：Chat Completions 请求、超时和结构化输出。
- `backend/src/services/kbService.js`：知识库路径、映射和上下文截断。
- `backend/src/services/engineRegistry.js`：Knowledge-AI engine。
- 对应专项路由的 prompt、fallback 和解析函数。
- `knowledge-base/`：行业文档和工具知识。

验证重点：AI 调用失败时有业务可用 fallback，结构化输出字段与前端消费字段一致，专业度达到验收手册标准。

## 修改部署或运行配置

需要检查：

- `backend/.env.example`
- `frontend/.env.example`
- `frontend/vite.config.js`
- `miniapp/vite.config.js`
- `.monkeycode/docs/环境配置清单.md`
- `.monkeycode/docs/部署运行手册.md`
- `.monkeycode/docs/安全与配置边界.md`

验证重点：开发代理、线上 API 路径、allowedHosts、PM2 服务名、健康检查和回滚路径。

## 修改运营后台

需要检查：

- `frontend/src/views/Admin.vue`
- `frontend/src/router/index.js` 中的 `requiresAdmin`。
- `backend/src/routes/admin.js`
- 数据模型、导出接口和敏感数据展示边界。

验证重点：后台入口只对高阶用户开放，导出接口受控，修改用户会员和反馈状态后数据一致。

- 数据表变化：`.monkeycode/docs/数据模型.md`

- 测试口径变化：`.monkeycode/docs/测试验收手册.md`
- 安全边界变化：`.monkeycode/docs/安全与配置边界.md`
