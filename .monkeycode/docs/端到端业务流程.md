# 端到端业务流程

## 入口到工具使用

用户进入 Web 站点后，前端 Vue Router 根据路径加载对应页面。公共入口包括首页、工具库、会员页、抖音 Hub、小红书 Hub、私域 Hub、诊断页和个人中心。

通用工具链路：

1. 用户在 `/tools` 或行业专版页选择工具。
2. 前端进入 `/tools/:code` 或专用工具页面。
3. 页面通过 `@/api/request` 或 `@/api/tool` 发起 API 请求。
4. 后端校验登录、会员等级和用量配额。
5. 后端执行计算器、模板、Knowledge-AI 或专项路由。
6. 后端写入 `tool_usage` 和必要的 `tool_results`。
7. 前端渲染结果、风险提示和升级引导。

## 注册登录流程

验证码流程：

1. 前端提交手机号到 `POST /api/auth/send-code`。
2. 后端生成验证码并写入 Redis key `code:<phone>`，有效期 300 秒。
3. 登录或注册时，后端校验 Redis 验证码或内测验证码。
4. 登录成功后，后端签发 JWT。
5. 前端把 token 写入 `localStorage.token`，请求拦截器自动注入 `Authorization`。

注册流程额外处理推荐关系：

1. 如果请求体包含 `referralCode`，后端查找推荐人。
2. 新用户写入 `users`，默认 `member_level=free`。
3. 后端为新用户生成 `referral_code`。
4. 如存在推荐人，推荐奖励逻辑更新推荐人奖励天数。

## 会员购买流程

Web 会员购买：

1. 前端会员页调用创建订单接口。
2. 后端读取 `backend/src/config/plans.js` 中的套餐价格、周期和名称。
3. 后端写入 `orders`，状态为 `pending`。
4. 支付回调进入 `POST /api/payment/callback`。
5. 后端校验 HMAC 签名和状态。
6. 支付成功时使用事务锁定订单。
7. 后端把订单状态改为 `paid`，并累加用户会员有效期。
8. 主事务完成后执行推荐佣金计算。

小程序支付流程通过 `POST /api/payment/create-miniprogram-order` 创建订单。当前返回模拟支付参数，代码中保留接入真实微信支付统一下单的 TODO。

## 会员权限流程

权限由前端入口和后端接口共同控制：

1. 前端根据 `localStorage.memberLevel` 和 `frontend/src/constants/membership.js` 展示入口状态。
2. 通用工具由 `backend/src/config/toolAccess.js` 控制工具等级。
3. 抖音、小红书、私域专项路由各自通过 `checkAccess` 查询 `users.member_level`。
4. `requireLevel()` 按 `free < starter < pro < annual` 判断是否放行。

修改权限时需要同步检查前端入口、通用工具配置和专项路由。

## 抖音经营闭环

抖音是当前最完整的样板链路。

```text
/douyin
  -> /douyin/diagnosis
  -> /douyin/quick-plan
  -> daily execution tools
  -> /douyin/video-diagnoser
  -> /api/douyin/review-records/insights
  -> next /douyin/quick-plan
```

具体流程：

1. 用户进入 `/douyin/diagnosis`，调用 `POST /api/douyin/diagnosis` 生成经营体检。
2. 体检结果携带行业、目标、短板和诊断上下文进入 `/douyin/quick-plan`。
3. 计划页调用 `POST /api/douyin/quick-plan` 生成 15 天作战表。
4. 计划生成后自动或手动保存到 `douyin_quick_plans`。
5. 用户可更新每日任务状态，状态写回保存计划。
6. 执行过程中可跳转脚本、标题、封面、转化、投流和复盘工具。
7. `/douyin/video-diagnoser` 调用 `POST /api/douyin/data-diagnoser` 生成复盘诊断。
8. 复盘页把输入、诊断结果、有效内容类型和下一步行动保存到 `douyin_review_records`。
9. 洞察接口读取最近 20 条复盘，生成有效内容类型排行和下一轮计划建议。
10. 下一轮计划页读取路由上下文，把复盘沉淀注入新的 15 天计划 prompt。

## 小红书增长链路

小红书模块围绕账号定位、内容生产、转化和投放组织。

主要流程：

1. 用户进入 `/xhs` 查看工具矩阵。
2. `POST /api/xhs/account-diagnosis` 生成账号体检。
3. 根据当前阶段进入起号计划、选题、脚本、标题、封面等内容工具。
4. 内容发布后使用笔记诊断、账号复盘、SEO、转化优化和投放工具。
5. 高阶工具如竞对分析、IP 定位、人设一致性由更高会员等级控制。

小红书专项接口统一走 `/api/xhs` 前缀，页面主要通过 `@/api/request` 请求。

## 私域运营链路

私域模块围绕体检、会员体系、复购留存、社群和裂变组织。

主要流程：

1. 用户进入 `/private` 查看私域工具矩阵。
2. `POST /api/private/diagnosis` 生成私域运营体检。
3. 根据短板进入会员体系设计、复购留存、社群 SOP、CAC vs LTV 等工具。
4. 年费等级可进入 90 天私域战略和裂变类高阶方案。

私域专项接口统一走 `/api/private` 前缀。

## 经营体检链路

站内通用诊断页包含阶段问题、创始人能力、企业租、快速扫描、IP 诊断和历史报告。

主要流程：

1. 前端通过 `/api/diagnosis/v3/*` 获取问题和参考数据。
2. 用户提交完整诊断数据到 `/api/diagnosis/v3/generate`。
3. 后端使用诊断引擎和 AI 诊断服务生成报告。
4. 报告保存到 `diagnosis_reports`。
5. 历史页按用户读取历史报告。

## 用户反馈流程

会员页可以提交反馈：

1. 前端调用 `POST /api/user-feedback` 保存反馈。
2. 用户可通过 `GET /api/user-feedback/my` 查看自己的反馈。
3. 后台通过 `/api/admin/user-feedbacks` 查看和处理反馈。

反馈表包含类型、标题、描述、图片、状态和后台备注。

## 后台运营流程

后台入口为 `/admin`，前端路由要求登录且本地会员等级达到 `annual`。后端后台路由挂载在 `/api/admin`，由路由内部逻辑读取用户、订单、工具使用、佣金、反馈、错误日志和配置。

常见后台动作：

- 查看统计、用户、订单和工具使用。
- 修改用户会员等级或延长到期时间。
- 处理推荐佣金状态。
- 处理用户反馈。
- 导出用户、订单、佣金和反馈数据。

后台导出类接口应作为敏感运营能力，生产环境需要结合部署网关和访问控制使用。
