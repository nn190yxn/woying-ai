# 前端状态管理手册

## 目标

本文档说明 Vue 前端的登录态、会员等级、配额状态、路由守卫和本地存储边界。新增页面、工具入口或权限判断时，应先检查本页。

## 状态模块

| Store | 文件 | 职责 |
| --- | --- | --- |
| `user` | `frontend/src/stores/user.js` | 登录 token、用户资料、会员等级、管理员判断 |
| `quota` | `frontend/src/stores/quota.js` | 全局配额、工具配额、当前工具、前端本地扣减 |

前端状态使用 Pinia composition store。

## 用户状态

`user` store 的核心 state：

| 字段 | 来源 | 含义 |
| --- | --- | --- |
| `token` | `localStorage.token` 或登录响应 | 当前登录 token |
| `userInfo` | 登录、注册或用户信息接口 | 当前用户资料 |
| `loading` | store 内部 | 登录、注册、拉取用户信息状态 |

核心 computed：

| 字段 | 含义 |
| --- | --- |
| `isLoggedIn` | 当前是否存在 token |
| `nickname` | 用户昵称 |
| `avatarText` | 头像首字 |
| `memberLevel` | 归一化后的会员等级 |
| `isAdmin` | 当前会员等级是否达到 `annual` |
| `memberLabel` | 会员展示名 |
| `memberExpireAt` | 会员到期时间 |
| `phone` | 手机号 |

## 登录和注册流

登录成功后：

```text
apiLogin()
  -> res.token
  -> res.user
  -> token ref
  -> userInfo ref
  -> localStorage.token
  -> localStorage.memberLevel
```

注册成功后的写入路径相同。

`fetchUserInfo()` 会读取用户接口并刷新 `userInfo` 与 `localStorage.memberLevel`。失败时会调用 `logout()` 清理本地登录态。

## 本地存储边界

| key | 写入位置 | 用途 |
| --- | --- | --- |
| `token` | `user.js`、登录和注册 | 请求头注入、路由守卫判断 |
| `memberLevel` | `user.js` | 管理员路由守卫和入口体验 |

注意：

- `localStorage.memberLevel` 只用于前端体验和路由判断。
- 后端接口权限仍以数据库中的 `users.member_level` 为准。
- 401 响应会由 `request.js` 清理 `localStorage.token` 并跳转登录。

## 路由守卫

路由文件：`frontend/src/router/index.js`。

守卫逻辑：

```text
to.meta.title -> 更新 document.title
to.meta.requiresAuth -> 检查 localStorage.token
to.meta.requiresAdmin -> 检查 localStorage.memberLevel 是否达到 annual
```

当前 `requiresAdmin` 用于 `/admin`。普通工具会员权限主要由页面入口、Hub 和后端接口控制。

新增需要登录的页面：

- 在路由 meta 中添加 `requiresAuth: true`。
- 页面接口仍需调用后端受保护接口。
- 登录页 redirect query 会记录原路径。

新增管理员页面：

- 在路由 meta 中添加 `requiresAuth: true` 和 `requiresAdmin: true`。
- 后端接口也要具备管理员或高阶会员权限判断。

## 请求状态和错误处理

请求封装：`frontend/src/api/request.js`。

行为：

- 默认 `baseURL` 为 `/api`。
- 请求超时为 30000 ms。
- 有 token 时自动注入 `Authorization`。
- 响应成功时直接返回 `response.data`。
- 401 时清理 token，并跳转 `/login`。
- 错误会写入 `error.normalized`。

页面捕获错误时优先使用：

```js
error.normalized?.message || error.message
```

## 配额状态

`quota` store 的核心 state：

| 字段 | 含义 |
| --- | --- |
| `globalQuota` | 全局配额响应 |
| `allQuotas` | 所有工具配额集合 |
| `currentToolCode` | 当前页面工具 code |
| `toolQuotas` | 单工具配额缓存 |
| `loading` | 配额读取状态 |

核心 computed：

| 字段 | 含义 |
| --- | --- |
| `globalRemain` | 全局剩余次数 |
| `globalTotal` | 全局总次数 |
| `currentToolQuota` | 当前工具配额 |
| `remain` | 当前工具剩余次数 |
| `total` | 当前工具总次数 |
| `isUnlimited` | 是否不限次 |

配额读取：

- `fetchGlobalQuota()`：读取全部配额并写入 `globalQuota` 和 `allQuotas`。
- `fetchAllQuotas()`：读取所有工具配额。
- `fetchToolQuota(code)`：读取单个工具配额。

工具页执行成功后可调用 `consume()` 做本地即时扣减，最终配额以后端 `tool_usage` 查询为准。

## 新增工具页面状态接入

新增工具页时建议流程：

1. 在页面初始化时设置当前工具 code。
2. 拉取当前工具配额或全局配额。
3. 提交前检查 `canUse()`。
4. 调用 API 时走 `@/api/request` 封装。
5. 成功后调用 `consume()`。
6. 捕获错误并展示 `error.normalized.message`。
7. 权限不足时展示升级引导。

## 会员状态展示

页面展示会员等级时应使用：

- `memberLevel`：逻辑判断。
- `memberLabel`：显示名称。
- `isAdmin`：后台入口展示。
- `memberExpireAt`：会员到期时间。

不要直接读取原始 `userInfo.memberLevel` 做等级比较，优先使用 `normalizeMemberLevel()` 和 `canAccessLevel()`。

## 常见问题

| 问题 | 排查点 |
| --- | --- |
| 登录后页面仍显示未登录 | `localStorage.token`、`userInfo`、`fetchUserInfo()` |
| 管理后台跳回首页 | `localStorage.memberLevel` 是否达到 `annual` |
| 接口 401 后循环跳转 | `request.js` 401 逻辑和登录页路径 |
| 前端显示高阶，接口返回 403 | 数据库会员等级与本地 `memberLevel` 不一致 |
| 配额显示未更新 | 是否调用 `fetchToolQuota()` 或 `consume()` |
| 新页面标题异常 | 路由 `meta.title` 是否配置 |
