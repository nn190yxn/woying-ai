# 发布验收记录模板

## 使用说明

每次发布或内测交付前复制本模板到对应执行记录文档中填写。记录中只写命令、状态、路径、响应摘要和键名存在性，不写真实密钥、数据库密码、JWT_SECRET、支付密钥、私钥内容或 `.env` 真实值。
