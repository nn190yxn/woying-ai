# 日志与可观测性手册

## 目标

本文档说明我赢AI后端日志、慢请求、审计事件和线上排查证据的使用方式。日志实现位于 `backend/src/middleware/logger.js`。

## 日志配置

| 配置 | 含义 | 默认值 |
| --- | --- | --- |
| `LOG_DIR` | 日志目录 | 当前进程目录下 `logs/` |
| `LOG_LEVEL` | 日志级别 | `info` |
| `SLOW_THRESHOLD_MS` | 慢请求阈值 | `2500` |

日志级别顺序：`error`、`warn`、`info`、`debug`。

## 日志文件

| 文件 | 来源 | 内容 |
| --- | --- | --- |
| `request.log` | HTTP 请求、应用 info/warn/debug、慢请求 | 请求状态、模块日志、慢请求 |
| `error.log` | 错误日志 | 未处理异常、工具失败、数据库生产查询失败 |
| `audit.log` | 审计日志 | 工具执行、登录、注册、支付、会员、后台操作 |

日志按 JSON 行写入，每行包含：

```json
{
  "ts": "2026-07-10T00:00:00.000Z",
  "level": "info",
  "module": "http",
  "msg": "GET /api/health 200"
}
```

## 日志轮转

进程启动后会计算到午夜的时间，并在午夜执行轮转。轮转文件名格式：

```text
request-YYYY-MM-DD.log
error-YYYY-MM-DD.log
audit-YYYY-MM-DD.log
```

轮转失败会输出到进程 stderr。

## HTTP 请求日志

`requestLogger` 在所有路由前注册。每个请求完成后记录：

| 字段 | 含义 |
| --- | --- |
| `method` | HTTP 方法 |
| `url` | 请求路径 |
| `status` | HTTP 状态码 |
| `duration` | 请求耗时 |
| `ip` | 请求来源 IP |
| `userAgent` | User-Agent |
| `userId` | 已鉴权用户 ID，可能为空 |

状态分级：

- 2xx 和 3xx：`info`。
- 4xx：`warn`。
- 5xx：`error`。

## 慢请求日志

`perfMonitor` 在所有路由前注册。请求耗时超过 `SLOW_THRESHOLD_MS` 时写入 `request.log`。

慢请求字段：

| 字段 | 含义 |
| --- | --- |
| `method` | HTTP 方法 |
| `url` | 请求路径 |
| `duration` | 请求耗时 |
| `userId` | 当前用户 ID，可能为空 |

常见慢请求来源：

- AI 生成类接口。
- 知识库读取和大 prompt 生成。
- 数据库连接异常重试。
- 线上网络波动。

## 审计日志

`audit.log` 记录关键业务动作。

| 方法 | 模块 | 字段 |
| --- | --- | --- |
| `logger.toolStart()` | `tool` | `userId`、`toolCode`、`inputKeys` |
| `logger.toolSuccess()` | `tool` | `userId`、`toolCode`、`duration` |
| `logger.authLogin()` | `auth` | `userId`、`method`、成功状态 |
| `logger.authRegister()` | `auth` | `userId`、`method` |
| `logger.paymentCreate()` | `payment` | `userId`、`planCode`、`amount` |
| `logger.paymentCallback()` | `payment` | `orderId`、成功状态 |
| `logger.membershipUpgrade()` | `membership` | `userId`、原等级、新等级 |
| `logger.membershipDowngrade()` | `membership` | `userId`、原等级、新等级 |
| `logger.adminAction()` | `admin` | `adminId`、`action`、`target`、`detail` |

审计日志用于追踪关键业务链路，不应记录完整 token、真实密钥、支付签名或私钥内容。

## 错误追踪

全局错误中间件 `errorTracker` 在路由之后注册。未处理异常会写入 `error.log`。

错误字段：

| 字段 | 含义 |
| --- | --- |
| `method` | HTTP 方法 |
| `url` | 请求路径 |
| `ip` | 请求来源 IP |
| `userId` | 当前用户 ID，可能为空 |
| `stack` | 错误堆栈 |
| `body` | 请求体键名列表 |

生产环境响应只返回通用错误文案，开发环境会附带错误消息和堆栈。

## 数据库可观测性

数据库连接和查询异常通过 `logger` 记录。

常见日志：

| 日志 | 含义 |
| --- | --- |
| `MySQL connected` | MySQL 连接成功 |
| `MySQL unavailable, using in-memory mock` | 非生产环境进入 mock DB |
| `Query failed in production` | 生产环境查询失败 |
| `user_sheets table ready` | 用户表格表初始化完成 |
| `douyin_quick_plans table ready` | 抖音计划表初始化完成 |
| `douyin_review_records table ready` | 抖音复盘表初始化完成 |

生产排查重点是确认线上使用真实 MySQL，且没有出现 `Query failed in production`。

## 知识库可观测性

知识库服务在路径越界时会记录：

```text
Path traversal attempt blocked
```

知识库相关问题排查顺序：

1. 检查 `KB_ROOT_PATH` 指向的目录是否存在。
2. 检查工具 code 与知识库映射。
3. 检查上下文长度配置。
4. 检查工具结果是否出现 fallback。

## AI 生成可观测性

AI 问题通常通过接口响应、慢请求日志、工具失败日志和 deep:test 报告定位。

重点观察：

| 现象 | 可能原因 | 证据 |
| --- | --- | --- |
| 请求超过阈值 | 上游慢、prompt 长、输出长 | `Slow request detected` |
| 工具失败 | AI 异常、解析失败、输入异常 | `Tool execution failed` |
| `degraded=true` | fallback 生效 | 接口响应和 deep:test |
| JSON 解析失败 | 结构化输出不稳定 | 路由错误日志和测试报告 |

## 线上排查命令

```bash
# 查看 PM2 服务状态
pm2 status woying-backend

# 查看 PM2 运行日志
pm2 logs woying-backend

# 检查 HTTPS 健康接口
curl -fsS https://woyai.cn/api/health
```

如果需要读取日志文件，优先在服务器上检查 `LOG_DIR` 指向目录。

## 发布后观察清单

发布或重启后，至少观察：

- PM2 服务为 `online`。
- `/api/health` 返回 `status=ok`。
- `request.log` 中核心接口 HTTP 状态正常。
- `error.log` 没有新增 5xx 业务错误。
- `audit.log` 中关键工具执行成功。
- AI 生成接口未持续出现慢请求和 fallback。
- 数据库日志显示真实 MySQL 可用。

## 常见故障定位

| 故障 | 首看位置 | 进一步动作 |
| --- | --- | --- |
| 页面 401 | 浏览器 Network、`request.log` | 检查 token 和 `JWT_SECRET` |
| 会员接口 403 | 接口响应、用户表会员等级 | 检查前后端权限矩阵 |
| 工具 500 | `error.log`、工具路由 | 检查 AI、知识库和输入校验 |
| 工具 degraded | deep:test 报告、接口响应 | 检查 fallback 原因 |
| 保存计划失败 | `error.log`、`douyin_quick_plans` | 检查表初始化和 JSON 字段 |
| 复盘洞察为空 | 接口响应、`douyin_review_records` | 检查当前用户复盘数量 |
| 支付异常 | `audit.log`、订单记录 | 检查回调签名和订单状态 |

## 日志安全边界

允许记录：

- 用户 ID。
- 工具 code。
- 输入字段名。
- 订单 ID。
- HTTP 路径、状态码和耗时。
- 错误消息摘要。

避免记录：

- 完整 token。
- 真实 API Key。
- 数据库密码。
- JWT 签名值。
- 支付密钥和签名原文。
- SSH 私钥内容。
- 用户完整敏感输入。
