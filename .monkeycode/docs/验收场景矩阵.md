# 验收场景矩阵

## 使用方式

本矩阵用于把测试命令、业务场景和验收证据对应起来。每次功能开发、线上部署或内测交付时，按影响范围选择对应场景执行。

状态使用：`PASS`、`FAIL`、`BLOCKED`、`N/A`。

## 核心冒烟场景

| 场景 | 入口 | 通过标准 | 证据 |
| --- | --- | --- | --- |
| 主站首页 | `GET /` | 页面可加载，核心资源无 404 | HTTP 和浏览器检查 |
| 健康检查 | `GET /api/health` | 返回 `status=ok` | curl 输出 |
| 登录 | `/login`、`/api/auth/login` | 返回 token，前端写入登录态 | 接口响应摘要 |
| 工具库 | `/tools` | 工具列表可加载，入口可点击 | 页面检查 |
| 会员页 | `/membership` | 套餐、权益和购买入口可展示 | 页面检查 |
| 后端核心冒烟 | `npm run smoke:core` | 无 HTTP 失败，非预期降级为 0 | 命令输出 |

| 用户等级 | 场景 | 通过标准 | 证据 |

| `pro` | 使用复盘和高级分析 | 可访问复盘、投流、组品等能力 | 页面和接口 |
| `annual` | 访问后台和高阶工具 | 可访问年费权益范围内页面 | 页面和接口 |

## 数据和持久化场景

| 场景 | 通过标准 | 证据 |
| --- | --- | --- |
| 用户隔离 | A 用户无法读取 B 用户计划、复盘、历史 | 双账号接口检查 |
| JSON 字段 | 写入后读取可解析，前端可渲染 | 接口响应样例 |
| mock DB | 本地非生产可跑通关键路径 | 本地测试 |
| 真实 MySQL | 生产环境查询失败会抛错 | 日志或配置检查 |
| 新表初始化 | 新表存在初始化或迁移路径 | `db.js` 或部署记录 |
