## 容易混淆的术语

| 术语 | 区分 |
| --- | --- |
| 体检 vs 复盘 | 体检用于开始前判断短板；复盘用于执行后基于真实数据做下一轮建议。 |
| 通用工具 vs 专项工具 | 通用工具走 `/api/generate/:toolCode`；专项工具走 `/api/douyin`、`/api/xhs`、`/api/private`。 |
| 前端权限 vs 后端权限 | 前端权限控制入口体验；后端权限决定接口实际放行。 |
| mock DB vs 真实 MySQL | mock DB 只适合本地开发；生产环境应使用真实 MySQL。 |
| fallback vs 正常 AI 输出 | fallback 是兜底保障；正常 AI 输出应优先满足结构和专业度。 |
| `degraded=false` vs 专业度通过 | `degraded=false` 只说明未降级；专业度还要看行业基准、行动建议和风险边界。 |
