# 代码目录导览

## 根目录

```text
woying-ai/
  backend/          Express API 服务
  frontend/         Vue 3 + Vite Web 前端
  miniapp/          uni-app 微信小程序
  knowledge-base/   AI 工具知识库 Markdown
  docs/             人工验收、测试和运营记录
  .monkeycode/      规格、Wiki 和项目级协作资料
```

## 前端目录

前端入口在 `frontend/src/main.js`，路由在 `frontend/src/router/index.js`。

```text
frontend/src/
  api/          Axios 请求封装和工具 API
  assets/       静态资源
  components/   页面组件和复用业务组件
  constants/    会员、工具目录、诊断推荐等常量
  icons/        工具和栏目图标
  router/       Vue Router 配置
  stores/       Pinia 状态
  styles/       全局样式
  views/        页面级组件
```

### api

- `request.js`：Axios 实例，默认 `/api`，自动注入 JWT，401 自动跳转登录。
- `index.js`：通用工具生成、配额、历史和前端事件上报。
- `tool.js`：工具列表、运行、生成、配额和历史封装。
- 其他 API 文件按业务模块封装，例如认证和会员。

新增页面请求时优先复用 `request.js`，保持错误规范化和 token 注入一致。

### constants

- `membership.js`：会员等级、标签、归一化和访问判断。
- `toolCatalog.js`：前端工具目录、分类、徽标、路径和入口元数据。
- `diagnosisRecommendations.js`：体检报告推荐动作共享配置。
- `douyinQuickPlan.js`：抖音 15 天计划展示选项、状态样式、字段标签、行业归一化别名和短板目标映射。`QuickPlanAgent.vue` 基于该常量模块渲染表单与状态选项，通过标准字段优先的展示行归一化兼容旧保存计划字段，区分当前上下文生成计划与手动加载保存计划的展示优先级，并在复盘跳转中携带计划 meta 与精简 `planContext`。QuickPlan 前端收口验证使用 `cd frontend && npm run build`。

工具入口、会员展示和 Hub 页面通常依赖这里的配置。

### stores

- `user.js`：登录状态、用户资料、会员等级、管理员判断和本地存储同步。
- `quota.js`：工具配额、当前工具配额、全局配额和本地扣减。

`user.js` 会把 token 写入 `localStorage.token`，把会员等级写入 `localStorage.memberLevel`。路由守卫和请求封装都依赖这些值。

### views

页面按业务分层：

- `views/Home.vue`：首页。
- `views/Tools.vue`、`views/ToolPage.vue`：通用工具库。
- `views/douyin/`：抖音专项工具页面。
- `views/xhs/`：小红书专项工具页面。
- `views/private/`：私域专项工具页面。
- `views/tools/`：通用和行业工具页面。
- `views/Admin.vue`：运营后台。
- `views/Login.vue`、`views/Register.vue`、`views/UserCenter.vue`：账号相关页面。

新增页面时需要同步检查 `router/index.js`、入口 Hub、工具目录和权限文案。

### styles

- `variables.css`：全站设计令牌，包含工作台背景、状态色、布局宽度、断点、卡片密度、按钮尺寸、圆角和阴影。
- `main.css`：全局基础样式，包含 `.container-wide`、按钮、卡片、面板、徽章、状态标签、表单、`workbench-*` 共享布局类和 `task-flow-nav` 页面级任务链路。

工作台式页面优先复用 `workbench-page-header`、`workbench-section`、`workbench-section-header`、`workbench-grid-*`、`status-badge` 和现有 `.card` / `.panel` 基础类。专项任务页的通用表单、结果、错误和升级提示样式位于 `views/agent-common.css` 与 `views/douyin/agent-common.css`。

全站布局重构规格位于 `.monkeycode/specs/site-layout-system-refactor/`，当前验证命令：

```bash
cd frontend
npm run test:layout-structure
npm run test:quick-plan-structure
npm run build
```

## 后端目录

后端入口在 `backend/src/index.js`。

```text
backend/src/
  config/       价格、Redis、工具权限等配置
  middleware/   鉴权、日志、性能和错误处理中间件
  models/       MySQL 查询入口和 mock DB
  routes/       API 路由
  services/     AI、知识库、计算器、诊断、结果协议等服务
  utils/        推荐返利等工具函数
```

### config

- `plans.js`：会员套餐价格、周期和展示名，是后端价格权威来源。
- `toolAccess.js`：通用工具会员等级要求和访问判断。
- `redis.js`：真实 Redis 与 mock Redis 切换。
- `mockRedis.js`：内存 Redis，实现验证码 TTL 等基础能力。

### middleware

- `auth.js`：JWT 鉴权、guest mode 和可选鉴权。
- `logger.js`：结构化日志、请求日志、审计日志、错误处理中间件和性能监控。

新增受保护接口应优先复用 `authMiddleware`。专项路由如果使用内部 `checkAccess`，需要保持会员等级和用户隔离一致。

### models

- `db.js`：MySQL 连接池、`query()`、`getConnection()` 和基础表初始化；抖音保存计划表会兼容补齐 `plan_version` 和 `input_hash`。
- `mockDb.js`：本地内存 mock 数据层，覆盖用户、订单、工具、体检、抖音计划和复盘记录。

新增持久化能力时，同步检查真实 DB 初始化和 mock DB 行为。

### routes

核心路由：

- `auth.js`：注册、登录、验证码。
- `user.js`：用户资料。
- `tool.js`：工具列表、配额、运行和历史。
- `generate.js`：通用工具生成入口。
- `douyinAgents.js`：抖音专项工具和经营闭环。
- `xhsAgents.js`：小红书专项工具。
- `privateAgents.js`：私域专项工具。
- `diagnosis.js`：通用经营体检。
- `payment.js`：订单和支付回调。
- `admin.js`：运营后台。
- `sheets.js`：用户表格保存。
- `posterGenerator.js`：海报生成。
- `security.js`：内容安全检测。
- `tokenMonitor.js`：token 用量统计。

新增路由后需要在 `backend/src/index.js` 挂载，并更新接口文档和路由映射文档。

### services

核心服务：

- `ai.js`：Chat Completions 调用封装。
- `kbService.js`：知识库检索和上下文读取。
- `engineRegistry.js`：工具执行引擎注册。
- `failover.js`：工具执行 failover。
- `resultSchema.js`：统一结果结构。
- `calculatorEngine.js`、`calculatorTools.js`：计算器输入和公式。
- `toolPayloadNormalizer.js`：工具 payload 归一化。
- `diagnosisEngine.js`、`diagnosisEngineV3.js`、`aiDiagnosis.js`：经营体检相关逻辑。
- `analytics.js`：行为事件。
- `tokenMonitor.js`、`qualityFeedback.js`：模型用量和质量反馈。
- `douyin/`：抖音 15 天计划链路服务模块边界，包含输入归一化、诊断上下文字段补齐、标准 input hash、行业/目标策略包、15 天日任务模板、规则计划生成、QuickPlanResult 校验、兼容字段补齐和保存计划迁移。保存计划迁移函数会补齐旧计划展示字段并保留 day status。`douyinAgents.js` 的 15 天计划生成和保存补齐路径已接入这些服务函数，路由文件内旧 QuickPlan fallback 和重复归一化逻辑已清理。

生成类工具改动通常会同时涉及 routes、services、knowledge-base、frontend views 和测试 payload。

### scripts

- `quick-plan-*.test.js`：QuickPlan 测试脚本集合，使用 `node --test` 覆盖输入归一化、规则生成器、保存计划迁移、保存计划接口、语义矩阵和属性断言。后端收口时配合 `node --check src/routes/douyinAgents.js`、`node --check src/services/douyin/*.js`、`npm run test:douyin-diagnosis` 与 QuickPlan 测试脚本一起执行。

## 小程序目录

小程序位于 `miniapp/`，使用 uni-app。

```text
miniapp/
  package.json
  vite.config.js
  src/
```

命令：

```bash
cd miniapp
npm run dev:mp-weixin
npm run build:mp-weixin
```

`miniapp/vite.config.js` 已配置 `allowedHosts: ['.monkeycode-ai.online']`。

## 知识库目录

`knowledge-base/` 存放 AI 工具可读取的 Markdown 知识。后端 `kbService.js` 会按工具 code 或行业映射读取相关内容，并注入生成 prompt。

知识库变更应同步验证：

- 对应工具能命中文档。
- 上下文长度没有被过度截断。
- AI 失败时 fallback 仍可输出可渲染结构。
- 专业度深测仍满足行业依据和行动建议要求。

## 文档目录

`.monkeycode/docs/` 是当前项目 Wiki。新增架构、接口、数据模型、运行、排错、安全、流程和路由映射类文档都放在这里。

`.monkeycode/specs/` 存放需求、设计和任务清单。当前整站重构规格在 `.monkeycode/specs/site-business-ops-refactor/`。

## 常见入口速查

| 要做的事 | 优先看 |
| --- | --- |
| 新增页面 | `frontend/src/router/index.js`、`frontend/src/views/` |
| 新增通用工具 | `backend/src/routes/generate.js`、`frontend/src/views/tools/`、`toolCatalog.js` |
| 新增专项工具 | 对应 `routes/*Agents.js` 和 `views/douyin|xhs|private/` |
| 改会员权限 | `membership.js`、`toolAccess.js`、专项 `requireLevel()` |
| 改支付价格 | `backend/src/config/plans.js` |
| 改登录鉴权 | `auth.js`、`middleware/auth.js`、`api/request.js`、`stores/user.js` |
| 改持久化 | `models/db.js`、`models/mockDb.js`、相关 route SQL |
| 改 AI 输出 | `services/ai.js`、`kbService.js`、对应 route fallback |
| 改部署配置 | `.env.example`、`vite.config.js`、部署运行手册 |
