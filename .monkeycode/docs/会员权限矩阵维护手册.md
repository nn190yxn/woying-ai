# 会员权限矩阵维护手册

## 目标

本文档说明会员等级、工具权限、入口锁定、接口门禁和升级文案的维护方式。修改任何会员权益时，应同时检查本页列出的文件和验收场景。

## 会员等级

| 等级 | 展示名 | 产品定位 | 典型能力 |
| --- | --- | --- | --- |
| `free` | 免费版 | 感知价值 | 基础体检、基础内容、基础计算 |
| `starter` | 初阶版 | 日常经营 | 15 天计划、脚本、标题、封面、SOP |
| `pro` | 进阶版 | 诊断增长 | 复盘、投流、组品、转化和高级分析 |
| `annual` | 高阶版 | 专项系统 | 90 天战略、IP、深度竞对和专家校准 |

`trial` 在前端归一为 `free`。

## 权限来源

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 前端等级判断 | `frontend/src/constants/membership.js` | 等级顺序、标签、归一化、入口判断 |
| 前端工具入口 | `frontend/src/constants/toolCatalog.js` | 工具卡片、分类、路径、徽标和入口元数据 |
| 前端用户状态 | `frontend/src/stores/user.js` | 登录态、会员等级、管理员判断 |
| 通用工具权限 | `backend/src/config/toolAccess.js` | `TOOL_REQUIRED_LEVELS` 和权限元数据 |
| 专项路由权限 | `douyinAgents.js`、`xhsAgents.js`、`privateAgents.js` | `checkAccess` 和 `requireLevel()` |
| 套餐价格 | `backend/src/config/plans.js` | 套餐价格、周期和展示名 |
| 会员页面 | `frontend/src/views/Membership.vue` | 套餐展示、购买入口和权益文案 |

## 维护原则

- 后端接口权限是最终门禁。
- 前端入口权限用于体验和升级引导。
- 价格和周期以后端 `plans.js` 为准。
- 同一个工具 code 的前端入口、后端权限和测试 payload 要保持一致。
- 专项工具的页面权限和接口权限要同时检查。
- 免费层高频生成类能力需要限次或明确配额。

## 通用工具权限维护流程

修改通用工具权限时：

1. 更新 `backend/src/config/toolAccess.js`。
2. 检查 `frontend/src/constants/toolCatalog.js` 中的展示等级和徽标。
3. 检查工具页面是否展示正确升级引导。
4. 检查 `/api/tools` 返回的权限元数据。
5. 更新 `industry-tool-access-matrix.md`。
6. 更新 `验收场景矩阵.md` 中相关场景。

验证重点：

- 免费用户访问付费工具时后端返回 403。
- 达标会员可正常调用工具。
- 前端锁定状态和后端 `requiredLevel` 一致。
- 配额显示与实际消耗一致。

## 抖音专项权限维护流程

抖音工具权限分布在 `backend/src/routes/douyinAgents.js` 的 `requireLevel()` 调用和前端 Hub 页面。

关键能力建议：

| 能力 | 建议等级 |
| --- | --- |
| 抖音体检 | `free` |
| 15 天计划 | `starter` |
| 脚本、标题、封面等执行工具 | `starter` |
| 视频数据复盘 | `pro` |
| 复盘洞察 | `pro` |
| 90 天深度战略 | `annual` |

修改时检查：

- `DouyinAgentHub.vue` 入口锁定和文案。
- `QuickPlanAgent.vue` 保存计划和任务状态权限。
- `VideoDiagnoserAgent.vue` 复盘和洞察权限。
- `/api/douyin/*` 接口直接调用结果。
- `DouyinBusinessLoop.md` 和 `ReviewInsights.md`。

## 小红书专项权限维护流程

小红书权限集中在 `xhsAgents.js` 和 `XhsAgentHub.vue`。

建议边界：

- 基础账号体检可作为低门槛入口。
- 起号计划、选题、脚本和封面适合 `starter`。
- 笔记诊断、账号复盘和投放分析适合 `pro`。
- 长期 IP 和深度策略适合 `annual`。

修改后同步：

- `模块/XhsGrowth.md`
- `前后端路由映射.md`
- `验收场景矩阵.md`

## 私域专项权限维护流程

私域权限集中在 `privateAgents.js` 和 `PrivateAgentHub.vue`。

建议边界：

- 私域体检可作为低门槛入口。
- 会员体系、社群 SOP 和复购留存适合 `starter` 或 `pro`。
- CAC vs LTV、90 天私域战略适合 `pro` 或 `annual`。

修改后同步：

- `模块/PrivateOps.md`
- `前后端路由映射.md`
- `验收场景矩阵.md`

## 管理后台权限

前端 `/admin` 路由通过 `requiresAdmin` 判断，当前 `isAdmin` 来自 `canAccessLevel(memberLevel, 'annual')`。

维护要求：

- 前端入口只对高阶用户展示或放行。
- 后端 `/api/admin` 需要服务端权限控制。
- 后台操作写入 audit 日志。
- 新增后台能力时评估数据隐私边界。

## 升级引导文案

升级引导应绑定具体经营结果。

推荐口径：

| 当前等级 | 引导方向 | 示例 |
| --- | --- | --- |
| `free` | 升级初阶 | 解锁 15 天计划和执行工具 |
| `starter` | 升级进阶 | 解锁复盘、投流和增长诊断 |
| `pro` | 升级高阶 | 解锁 90 天战略、IP 和深度专项 |

文案应出现在：

- 工具卡片锁定态。
- 接口 403 后的页面提示。
- 生成结果中的 `customizationCTA` 或 `upgradeHint`。
- 会员页套餐说明。

## 权限变更验收矩阵

| 账号等级 | 前端入口 | 后端接口 | 预期 |
| --- | --- | --- | --- |
| 未登录 | 受保护页面 | 需要登录接口 | 跳转登录或 401 |
| `free` | 免费工具 | 免费接口 | 可访问 |
| `free` | 初阶工具 | 初阶接口 | 锁定或 403 |
| `starter` | 初阶工具 | 初阶接口 | 可访问 |
| `starter` | 进阶工具 | 进阶接口 | 锁定或 403 |
| `pro` | 进阶工具 | 进阶接口 | 可访问 |
| `pro` | 高阶工具 | 高阶接口 | 锁定或 403 |
| `annual` | 高阶工具和后台 | 高阶接口 | 可访问 |

## 常见风险

| 风险 | 处理方式 |
| --- | --- |
| 前端显示可用，接口返回 403 | 对齐 `toolCatalog.js` 和后端 `requiredLevel` |
| 前端锁定，接口可调用 | 提升前端入口等级或收紧后端权限 |
| 会员页价格和支付价格不一致 | 以后端 `plans.js` 为准并同步会员页 |
| 专项工具遗漏权限 | 检查 `requireLevel()` 调用 |
| 免费层无限调用高频工具 | 检查配额和 `tool_usage` |
| 文档矩阵过期 | 同步 `industry-tool-access-matrix.md` 和本手册 |

## 权限变更提交前检查

```bash
# 前端构建
cd frontend
npm run build

# 后端相关文件语法检查
cd ../backend
node --check src/config/toolAccess.js
node --check src/routes/douyinAgents.js
node --check src/routes/xhsAgents.js
node --check src/routes/privateAgents.js
```

同时检查：

- `MembershipAndAccess.md` 已更新。
- `industry-tool-access-matrix.md` 已更新。
- `前后端路由映射.md` 已更新。
- `验收场景矩阵.md` 已更新。
- 403 响应包含可展示的错误或升级信息。
