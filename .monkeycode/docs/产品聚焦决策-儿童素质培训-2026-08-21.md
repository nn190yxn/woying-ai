# 我赢AI第一阶段聚焦决策

> 作者：Monkeycode  
> 决策日期：2026-08-21

## 决策

- 唯一项目根目录：`E:\程序开发\我赢AI\woying-ai`
- 第一阶段行业：儿童素质类培训。
- 首个验证场景：少儿体育培训。
- 第一阶段商业模式：软件 + 陪跑服务。
- 医美行业：保留为后续候选，但儿童素质培训尚未跑通前不并行开发。

## 选择理由

1. 创始人正在经营少儿体育培训业务，理解真实经营流程。
2. 已有部分经营结果，可用于建立基线、案例和产品方法论。
3. 能够获得种子用户和行业资源，降低早期获客与验证成本。
4. 儿童素质培训依赖持续获客、试听邀约、到店体验、报名转化、续费和转介绍，适合建立可量化闭环。
5. 相比直接进入医美，专业和广告合规风险更可控。

## 第一阶段核心产品

**儿童素质培训15天抖音获客陪跑系统**

```text
机构与课程建档
→ 获客诊断
→ 15天每日任务
→ 选题与脚本
→ 发布前顾问审核
→ 线索与邀约跟进
→ 到店体验与报名
→ 每3天真人纠偏
→ 15天结果复盘
```

## 最小数据闭环

- 机构、校区、课程和体验产品
- 抖音账号与内容
- 每日任务及完成状态
- 投放费用
- 有效线索
- 联系与邀约
- 到店体验
- 报名成交
- 续费与转介绍
- 顾问干预及结果

## 验证指标

1. 15天任务完成率。
2. 首次有效内容产出时间。
3. 有效线索数量与成本。
4. 邀约率和到店体验率。
5. 体验转报名率。
6. 首周期续费或转介绍率。

## 暂停事项

第一阶段不新增医美版本，不继续横向扩展更多行业；小红书、泛私域、零散工具和复杂会员体系暂不作为主要研发方向。
