# 前后端路由映射

## 请求封装

前端统一请求封装位于 `frontend/src/api/request.js`：

- 默认 `baseURL` 为 `/api`。
- 可通过 `VITE_API_BASE_URL` 覆盖。
- 请求自动读取 `localStorage.token` 并注入 `Authorization: Bearer <token>`。
- 响应直接返回 `response.data`。
- 401 会清理 token 并跳转 `/login`。

Vite 开发代理在 `frontend/vite.config.js` 中配置，`/api` 代理到 `VITE_API_TARGET` 或默认目标。

## 通用生成工具映射

大量行业工具页面通过 `@/api/index.js` 的 `generateTool()` 或 `@/api/tool` 的 `generateWithAI()` 进入后端。

通用路径：

```text
frontend tool page
  -> POST /api/generate/:toolCode
  -> backend/src/routes/generate.js
  -> calculator / template / knowledge-ai / fallback
```

工具历史和配额路径：

- `GET /api/tools/:code/quota`
- `POST /api/tools/:code/run`
- `GET /api/tools/:code/history`
- `GET /api/tools/history`

## 海报生成映射

海报模块存在两个挂载前缀：

- `/api/generate/poster`
- `/api/poster-generator`

主要接口：

- `GET /types`
- `GET /types/:code`
- `POST /prompt`
- `POST /generate`

前端页面 `/tools/poster` 对应 `views/tool/PosterGenerator.vue`。

## 表格保存映射

用户表格接口前缀：`/api/sheets`。

| 接口 | 用途 |
| --- | --- |
| `POST /api/sheets/save` | 按 `user_id + sheet_code` 保存或覆盖表格数据 |
| `GET /api/sheets/load/:id` | 读取指定表格 |
| `GET /api/sheets/list` | 读取当前用户表格列表，可按 `sheetCode` 过滤 |

## 内容安全和监控映射

内容安全接口：

- `POST /api/security/check-text`
- `POST /api/security/check-image`

Token monitor 接口：

- `GET /api/token-monitor/today`
- `GET /api/token-monitor/summary`
- `GET /api/token-monitor/recent`
- `GET /api/token-monitor/pricing`
- `GET /api/token-monitor/dashboard`

生产环境应结合安全与配置边界文档评估这些接口的访问控制。
