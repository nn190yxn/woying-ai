# 平台基础能力实施计划

> 作者：Monkeycode  
> 依据：`docs/superpowers/specs/2026-08-22-platform-foundation-design.md`  
> 范围：机构权限、服务器文件存储、异步任务可靠性；不接入 OSS/S3/Redis，不部署线上环境。

- [x] 1. 实现机构权限与成员管理闭环
  - [x] 1.1 在 `backend/src/services/organization.js` 增加角色能力矩阵、成员列表、成员添加、角色变更、成员移除和默认机构切换服务；所有操作基于服务端机构成员关系。
  - [x] 1.2 新增或扩展机构权限中间件，提供机构成员、机构管理员、营销负责人、顾问分配关系等统一校验；禁止仅依赖请求体中的 organizationId。
  - [x] 1.3 扩展 `backend/src/routes/organizations.js`，增加成员、默认机构和网点 CRUD API，并对每个写操作绑定角色权限。
  - [x] 1.4 在 `backend/src/models/db.js` 与 `backend/src/models/mockDb.js` 中补齐成员、默认机构、网点和权限审计所需的幂等结构与操作语义。
  - [x] 1.5 接入机构资源、文件、异步任务和顾问服务的角色校验，保证成员移除后立即失去访问权。
  - [x] 1.6 编写角色允许/拒绝矩阵、成员生命周期、默认机构切换、网点隔离、顾问分配和跨机构访问测试。
  - [x] 1.7 检查点：机构权限专项测试全部通过，旧机构隔离测试不回归。

- [x] 2. 实现服务器文件存储安全闭环
  - [x] 2.1 新增 `StorageAdapter` 契约及服务器磁盘适配器，改造 `privateStorage.js` 使用环境变量存储根目录和服务端生成的存储键。
  - [x] 2.2 增加文件 MIME 白名单、扩展名匹配、最大大小、声明值一致性、哈希和路径穿越校验；保留音视频时长扩展点并要求人工确认状态。
  - [x] 2.3 将机构 ID、资产 ID、用途和过期时间纳入签名内容，读取时校验机构归属、资产状态、过期时间和物理文件存在性。
  - [x] 2.4 扩展 `backend/src/routes/storage.js`，按机构角色限制创建、上传、签名读取和删除；补充资产列表与状态处理接口。
  - [x] 2.5 增加过期资产扫描、物理文件清理和 pending 孤儿资产回收服务，确保清理过程幂等且不越机构边界。
  - [x] 2.6 编写存储适配器契约、非法 MIME/扩展名/大小、哈希、跨机构签名、过期删除、路径穿越和上传失败回收测试。
  - [x] 2.7 检查点：文件存储专项测试全部通过，既有私有资产测试和前端构建不回归。

- [x] 3. 实现异步任务可靠性与独立 Worker
  - [x] 3.1 在 `backend/src/models/db.js` 与 `backend/src/models/mockDb.js` 中补齐任务租约、锁定者、锁定时间、下次运行时间和结果幂等字段，保持幂等补列。
  - [x] 3.2 重构 `backend/src/services/asyncTasks.js` 的任务状态机，实现数据库原子 claim、租约超时恢复和多进程重复领取保护。
  - [x] 3.3 增加取消令牌与状态条件更新，确保取消中的任务不会在完成后覆盖为 succeeded；支持受控进度回调。
  - [x] 3.4 增加指数退避、最大重试次数、失败分类和 next_run_at 调度，处理数据库唯一冲突时重新读取已有幂等任务。
  - [x] 3.5 为业务结果写入增加结果幂等键，确保任务重试不会重复生成诊断、报告或其他业务结果。
  - [x] 3.6 新增 `backend/src/workers/asyncTaskWorker.js` 独立 Worker 入口，仅从任务处理器注册表执行允许的任务类型，并保证自然退出与启动失败可诊断。
  - [x] 3.7 扩展 `backend/src/routes/asyncTasks.js`，保持查询、取消、重试权限隔离；如增加提交入口，仅允许白名单任务类型。
  - [x] 3.8 编写多 Worker claim、取消竞态、重试退避、租约恢复、进度回调、跨进程幂等、业务结果唯一性和 Worker 生命周期测试。
  - [x] 3.9 检查点：异步任务专项测试全部通过，API、增长平台和旧任务兼容测试不回归。

- [x] 4. 完成三阶段集成验收
  - [x] 4.1 运行机构、存储、异步任务专项测试及现有增长平台、媒体渠道、Quick Plan 回归测试。
  - [x] 4.2 运行全部新增和修改后端文件语法检查，确认 API 进程与 Worker 均可自然退出。
  - [x] 4.3 运行前端生产构建，确认现有机构、文件和增长页面无构建回归。
  - [x] 4.4 更新 `README.md`、项目任务记忆和全局任务记忆，准确记录已验证结果、Mock DB 限制和未部署状态。
  - [x] 4.5 检查点：所有设计验收项有自动化证据，无线上部署和迁移动作。
