# 本地生活知识操作系统

作者：Monkeycode

## 项目简介

以儿童素质培训为第一阶段场景，建立可追溯、可审核、机构隔离的结构化知识及业务应用闭环。

## 使用方式

按 `tasklist.md` 查看实施范围；通过知识治理、检索、AI Runner、业务闭环专项测试与前端构建验收。

## 当前状态

任务1-8全部完成；知识治理、结构化检索、指标基线、顾问触发、API和前端闭环均已验收。未部署、未迁移线上数据。
