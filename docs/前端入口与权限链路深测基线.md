# 前端入口与权限链路深测基线

## 执行规则

- 本文件用于全量工具深测时核对前端页面入口、API 端点、鉴权状态和会员权限链路。
- 公网页面入口以 `https://woyai.cn` 为准，HTTP IP 入口当前返回 Nginx 404，不作为页面验收入口。
- API 请求统一通过 `/api` 前缀进入后端，前端请求层以 `frontend/src/api/request.js` 为基线。
- 任何记录不得包含 API Key、数据库密码、JWT_SECRET、支付密钥或 `.env` 真实值。
- 鉴权深测使用测试账号或安全 token 签发方案；无 token 基线应返回 401。

## 专项页面与 API 映射

| 模块 | 页面路径前缀 | API 前缀 | 权限基线 |
|---|---|---|---|
| 通用工具 | `/tools/:code` | `/api/generate/:toolCode` | 按 `toolAccess` 与会员等级判断 |
| 小红书专项 | `/xhs/*` | `/api/xhs/*` | 无 token 返回 401；低等级返回 403 |
| 抖音专项 | `/douyin/*` | `/api/douyin/*` | 无 token 返回 401；低等级返回 403 |
| 私域专项 | `/private/*` | `/api/private/*` | 无 token 返回 401；低等级返回 403 |
| 企业诊断 | `/diagnosis/*` | `/api/diagnosis/*` | 历史与详情页需要登录 |
| 会员中心 | `/membership` | `/api/membership/*` | 套餐公开，当前会员信息依赖登录态 |

## 权限场景

| 场景 | 请求状态 | 预期结果 |
|---|---|---|
| 未登录访问公开页面 | 无 token | 页面可访问，提交受保护接口时返回 401 |
| 未登录访问 `requiresAuth` 页面 | 无 token | 前端跳转 `/login?redirect=...` |
| 免费会员访问免费工具 | free token | 接口返回 200，结果包含统一结构 |
| 免费会员访问高阶工具 | free token | 接口返回 403 或页面展示升级引导 |
| 年费会员访问全量工具 | annual token | 接口返回 200，`degraded=false` 为优先验收目标 |
| token 失效 | 过期或非法 token | 接口返回 401，前端清理登录态并引导登录 |

## 链路检查项

| 检查项 | 验收标准 |
|---|---|
| 页面可达 | 路由返回 SPA HTML，首屏无空白 |
| 静态资源 | JS/CSS chunk 返回 200 |
| 表单字段 | 前端提交字段与 `backend/scripts/test-payloads.json` 和后端输入协议一致 |
| API 前缀 | 请求路径走 `/api`，由 Nginx 或开发代理转发到后端 |
| 401 处理 | 统一请求层识别 401 并引导登录 |
| 403 处理 | 页面展示升级提示或后端返回 `requiredLevel` |
| 结果结构 | 外层包含 `status/degraded/summary/meta`，领域工具保留 `result` 内层字段 |
| 会员引导 | 结果或权限提示保留升级/定制引导文案 |
