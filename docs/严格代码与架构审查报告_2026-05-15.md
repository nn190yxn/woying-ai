# 严格代码与架构审查报告（2026-05-15）

## 审查范围

- 统一结果协议：`backend/src/services/resultSchema.js`
- 执行引擎：`backend/src/services/engineRegistry.js`
- 降级链路：`backend/src/services/failover.js`
- 小红书专项：`backend/src/routes/xhsAgents.js`
- 抖音专项：`backend/src/routes/douyinAgents.js`
- 私域专项：`backend/src/routes/privateAgents.js`
- 通用工具总路由：`backend/src/routes/generate.js`
- 知识库接入层：`backend/src/services/kbService.js`、`backend/src/config/kb-mapping.json`
- 深度测试脚本：`backend/scripts/deep-test-runner.js`
- 线上运行证据：`docs/线上验收执行记录.md` 与最新 PM2 日志

## 总体结论

- 当前版本已经达到可内测上线状态。
- 当前系统已经完成统一外层协议收口。
- 当前系统仍处于“统一架构第一阶段”，还没有完全进入单一路由、单一知识库接入层、单一领域载荷规范。
- 当前剩余问题集中在三类：
  - 领域层载荷仍有历史兼容债务
  - 知识库接入仍有旁路
  - 智能主链路的降级率仍然偏高

## 分级发现

### P0

1. 抖音专项存在 `result.result` 双层嵌套。
   - 风险：破坏统一领域载荷语义，前端和测试都要写特殊分支。
   - 状态：已在本轮修复启动。

2. JWT 默认密钥回退值不一致。
   - 风险：在 `JWT_SECRET` 缺失或环境漂移时，不同路由会出现不一致鉴权结果。
   - 状态：已在本轮修复启动。

### P1

1. 统一结果协议当前是兼容层，不是最终统一载荷规范。
2. `knowledge-ai`、`rule-based-knowledge`、`rag` 三类工具仍未完全同构。
3. `privateAgents` 仍绕过 `kbService + kb-mapping` 主干，直接读取 Markdown 目录。
4. `deep-test-runner.js` 对结构兼容的识别范围偏窄，覆盖不到部分抖音/AI 工具。
5. 线上生成类工具日志中存在较多 `degraded=true` 历史记录。

### P2

1. `xhsAgents` 启动时同步读取结构化知识库文件。
2. `privateAgents` 每次请求重新扫描知识库目录，后续应缓存化。
3. 通用工具总线最完整，专项工具体系仍有历史分支。

1. 修复抖音专项双层 `result` 嵌套。
2. 收敛 JWT secret 获取逻辑。
3. 扩展深测脚本的结构兼容识别范围。

5. 对 `degraded=true` 工具做专项治理。

## 内测检查清单

### A. 权限与账号

1. 验证未登录访问免费工具、会员页、工具页行为。
2. 分别验证 `free/starter/pro/annual` 的访问边界和升级提示。
3. 同一 token 分别访问 `/api/xhs/*`、`/api/douyin/*`、`/api/private/*`、`/api/membership/current`，确认鉴权一致。

### B. 统一结果协议

1. 每类工具至少抽测 3 个接口。
2. 每个接口核对 `status/degraded/summary/meta/result`。
3. 检查前端是否依赖顶层字段或 `result` 内层字段。
4. 重点核对抖音接口是否还存在 `result.result.*`。

### C. 工具接口一致性

1. 核对前端工具入口、API 路径、`toolCode`、KB 映射 key 是否一致。
2. 核对诊断类、方案类、脚本类、选题类、计算类的结构是否一致。
3. 核对 401/403/参数错误/降级结果的返回结构是否一致。

### D. 知识库衔接

1. 抽查 `kbFilesUsed/kbFilesMissing/kbSectionsMissing`。
2. 对比不同会员等级在同工具上的知识库上下文深度差异。
3. 检查私域话术、KPI、复购/裂变内容是否为空。

### E. 降级与稳定性

1. AI 正常时核心工具应返回 `degraded=false`。
2. AI 异常时应稳定返回 `fallback` 或降级结果，并带 `riskNotes`。
3. 日志复查：MySQL 失败、401/403 聚集、JSON 解析错误、AI 403/429/5xx、慢请求。

### F. 前端页面体验

1. 首页与工具箱资源加载。
2. 小红书诊断、标题、转化计算器页面。
3. 抖音诊断、组品定价、内容策划、脚本、战略页面。
4. 私域诊断、会员体系、复购留存、裂变页面。
5. 生成类工具输出区块、CTA、风险说明、建议动作。

### G. 数据与埋点

1. 已登录调用是否写入 `tool_usage`。
2. guest mode 是否跳过持久化写入。
3. analytics 是否在访客模式下保持稳定。

### H. 线上运维

1. `pm2 list`
2. `/health`
3. `/api/health`
4. 最近 200 行日志
5. 核心接口复测：
   - `/api/xhs/account-diagnosis`
   - `/api/douyin/diagnosis`
   - `/api/private/diagnosis`
   - `/api/generate/gross-margin-restaurant`
   - `/api/generate/festival`
   - `/api/generate/fission`
   - `/api/generate/marketing-plan`
