# Kimi 2.6 全面内测交付任务说明书

更新时间：2026-05-15

适用对象：Kimi 2.6

目标阶段：上线前最后一轮全面内测与交付收口

## 1. 任务目标

本任务的最终工作节点是：

项目达到“可直接发送给甲方团队进行全面人工内测”的交付标准。

该标准要求：

- 结构稳定
- 全接口稳定
- 页面与接口真实联通
- 结果协议一致
- 无回退输出
- 无系统问题
- 无结构问题
- 无明确功能 bug
- 可以由甲方团队直接开展人工测试，无需再依赖开发现场补救

## 2. 当前基线

当前已经完成的核心工作：

- 抖音 Knowledge-AI 主路由已完成一轮结构化输出推广
- 抖音关键前端页面已接入真实接口
- 私域、小红书、通用工具的协议收口和部分抽测已完成
- 输入协议归一化、统一结果协议、统一请求层、线上最小部署流程已经建立
- 线上备份、最小同步、回测、文档回写机制已经跑通

当前抖音专项已形成闭环：

- 后端结构化输出已收口
- 前端真实接口已接通
- 线上静态资源与接口联调已通过

## 3. 剩余工作量评估

按功能点估算，当前可视为还有 5 个批次的内测工作。

按工具功能点估算：

- 通用工具：21 个
- 抖音专项：7 个
- 私域专项：7 个
- 小红书专项：4 个
- 合计：39 个功能点

当前已完成“结构收口和关键专项闭环”，距离“甲方可直接全面人工内测”的目标，还需要完成以下工作：

- 39 个功能点逐一跑通
- 所有关键页面逐一人工联调
- 会员、鉴权、配额、异常、降级等横向链路回归

- 输出完整的内测报告、问题清单、修复记录和最终交付说明

建议工作量判断：

- 还需要 2 到 3 个完整工作轮次
- 还需要 2 到 3 人天级别的有效执行量

## 4. 最终交付标准

只有满足以下全部条件，任务才算完成：

### 4.1 接口标准

- 核心业务接口全部返回 `status=ok`
- 有效样本下全部返回 `degraded=false`
- 不存在回退输出进入最终交付状态
- 不存在 `result.result`、结构拍平、关键字段缺失、字段名漂移等结构问题
- 接口响应时间、返回结构、错误提示都稳定可复现

### 4.2 页面标准

- 页面真实调用后端接口
- 页面可以完整展示成功结果
- 页面可以正确展示失败提示
- 页面可以正确处理登录态和会员态
- 页面不存在本地拼假数据冒充真实结果的情况

### 4.3 系统标准

- 前端构建通过
- 后端语法检查通过
- 后端核心服务在线
- 线上健康检查通过
- 不引入新的 PM2、数据库、鉴权、静态资源、请求层问题

### 4.4 质量标准

- 无 P0 问题
- 无 P1 问题
- 无已知结构缺陷
- 无已知接口回退缺陷
- 无已知页面功能阻断问题
- 无已知影响甲方人工测试的明显 bug

## 6. 执行规范

### 6.1 总体执行原则

- 发现问题后直接修复，不停留在分析层
- 修复后立即本地验证
- 修复后立即最小部署
- 部署后立即回测
- 回测后立即更新文档

### 6.2 线上执行顺序

每次线上变更必须按以下顺序执行：

1. 本地改动完成
2. 本地语法检查或构建通过
3. 打最小部署包
4. 线上创建备份
5. 上传并解压部署包
6. 前端执行 `npm run build` 或后端 `pm2 restart`
7. 做目标接口回测
8. 做轻量联调验收
9. 更新文档

### 6.3 安全与环境规范

- 不展示私钥内容
- 不展示 `.env` 真实内容
- 不在线上做 Git 操作
- 不覆盖线上真实 `backend/.env`
- 发现线上差异先备份再处理
- 只做最小同步

## 7. 测试标准

### 7.1 API 标准

每个接口测试都必须记录：

- 路由
- 样本输入摘要
- HTTP 状态
- `status`
- `degraded`
- `engineType`
- `result` 关键字段
- 是否需要继续回测

### 7.2 页面标准

每个页面测试都必须记录：

- 页面路径
- 是否可打开
- 是否成功发起请求
- 是否展示 loading
- 是否展示真实结果
- 是否展示错误提示
- 是否存在本地假数据残留

### 7.3 稳定性标准

- 短结构路由：8 次连续成功
- 长结构路由：12 次连续成功
- 页面联调：至少 1 次成功闭环

## 9. 严重级别定义

### P0

- 阻断核心页面打开
- 阻断核心接口使用
- 出现回退交付状态
- 出现系统级错误

### P1

- 结构错误导致页面无法正确消费
- 有效样本仍出现 `degraded=true`
- 会员限制、鉴权、页面关键交互错误

### P2

- 展示信息不完整
- 文案或字段映射偏差
- 非阻断体验问题
