# 线上验收执行记录

## 使用规则

- 每个执行 Agent 必须先读取本文件，再继续执行验收。
- 每完成一个阶段，必须立即更新对应阶段的“执行记录”。
- 不允许只在聊天里反馈结果，必须把命令、实际输出摘要、状态和下一步写回本文档。
- 严禁在本文档写入真实 API Key、数据库密码、JWT_SECRET、支付密钥或 `.env` 真实值。
- 只允许记录环境变量键名存在性和接口响应摘要。
- 状态只使用：`PENDING`、`IN_PROGRESS`、`PASS`、`FAIL`、`BLOCKED`。
- 任一阶段 `FAIL` 或 `BLOCKED` 时，停止后续阶段，先写“问题反馈记录”。
- 如果再次执行同一阶段，在该阶段下追加新的执行记录，不覆盖旧记录。
