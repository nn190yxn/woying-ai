# 本地生活知识操作系统接入我赢AI设计规格

> 作者：Monkeycode  
> 日期：2026-08-22  
> 状态：已获用户确认，待实施计划

## 1. 背景与目标

对 `E:\知识库\内容运营知识库\本地生活` 进行全量盘点后，共确认864个文件：603个Markdown、241个JSON、2个PDF、1个PPTX，以及图片、脚本和历史压缩包。

目标不是把原文直接做成普通RAG，而是建设一套供平台内部使用的知识操作系统：

```text
原始证据
→ 审核知识
→ 产品口径
→ 诊断规则
→ 行动卡
→ 复盘指标
→ 顾问服务触发
```

客户不直接阅读知识库原文，只接收基于知识生成的诊断、动作、验证指标、风险提示和服务建议。

第一阶段继续聚焦儿童素质培训，优先少儿体育培训；不扩展CRM、个人客户明细管理、自动营销群发或医美行业版本。

## 2. 产品原则

1. **结果优先**：知识必须服务于获客、执行、线索、到店、成交和续费结果。
2. **机构数据优先**：机构自身连续实测数据高于行业经验，行业经验高于单一专家观点。
3. **证据可追溯**：内部保存来源、版本、日期和派生关系；客户侧只展示必要的理由和证据摘要，不复现原文。
4. **动态知识降级**：平台规则、广告入口、价格、算法和阈值过期后不得作为确定性结论。
5. **儿童培训适配**：餐饮、团购、医美等跨行业经验只能作为受限类比，不得直接生成儿童培训硬规则。
6. **人工可接管**：冲突、数据不足、合规风险和连续无改善问题进入人工复核或顾问服务。
7. **隐私最小化**：不导入个人联系方式、用户ID、Token、签名URL、儿童姓名/影像及客户逐人跟进记录。

## 3. 知识分层架构

### 3.1 Raw Evidence 原始证据层

保存原始文件、抓取快照和不可直接编辑的解析结果，用于内部回溯。默认不进入产品问答上下文。

排除：隐藏工具目录、脚本、配置、工作记忆、凭证、Token、个人标识、未经授权的儿童和家长数据。

### 3.2 Curated Knowledge 审核知识层

将原始材料拆成原子知识对象。每条对象至少包含：

- `knowledge_id`
- `title`
- `statement`
- `industry`
- `product_domain`
- `channel`
- `scene`
- `knowledge_type`
- `source_refs`
- `source_date`
- `derived_from`
- `evidence_level`
- `applicable_conditions`
- `counterexamples`
- `volatility`
- `last_verified`
- `next_review`
- `license_status`
- `privacy_level`
- `status`
- `supersedes`
- `contradicts`

知识类型包括：`principle`、`formula`、`threshold`、`diagnostic_rule`、`sop`、`action_card`、`case`、`controversy`、`risk`、`metric`、`service_trigger`、`platform_fact`、`skill_context`。

### 3.3 Product Canonical 产品口径层

只保留经过审核、可进入产品运行的儿童培训口径。每个主题只有一个当前规范版本，旧版本保留但默认不检索。

知识状态：

- `raw`
- `pending_review`
- `verified`
- `canonical`
- `conflicted`
- `expired`
- `revoked`
- `archived`

## 4. 知识治理与检索

### 4.1 标签维度

检索至少按以下维度过滤：

- 行业：儿童体育、舞蹈、美术、音乐、语言、综合素质；
- 产品域：获客、内容、投流、线索、到店、成交、教学交付、续费；
- 渠道：抖音、小红书、视频号、本地、线下；
- 场景：冷启动、招生季、节点活动、日常获客、续费、周复盘；
- 证据：机构数据、多来源共识、融合规则、单作者经验、案例类比；
- 时效：稳定、季度复核、即时复核。

### 4.2 检索排序

1. 当前机构历史基线和已验证数据；
2. 儿童培训多机构验证知识；
3. 多来源融合口径；
4. 原始证据摘要；
5. 单一作者经验；
6. 跨行业类比。

同一派生链只注入一个主版本，其他版本仅作为内部溯源，不因重复出现而提高可信度。

### 4.3 动态规则

以下内容必须带 `requires_verification=true`，并在到期后降级：

- A3判定和有效期；
- 平台算法与流量权重；
- 广告入口、佣金、券和补贴；
- 固定CTR、完播率、ROI和投放半径；
- 后台字段、按钮和审核规则；
- 平台案例中的增长比例。

默认复核周期：平台功能7—30天，趋势与阈值30—90天，稳定经营原则按季度或事件复核。

## 5. 平台能力设计

### 5.1 经营漏斗诊断

统一漏斗：

```text
曝光 → 点击/阅读 → 有效咨询 → 预约 → 到店 → 完成体验 → 正价报名 → 教学交付 → 续费/转介绍
```

诊断输出固定为：

```text
现象 → 数据证据 → 主因 → 次因 → 动作 → 验证指标 → 停止条件
```

首批诊断规则：

- 流量不足：先检查人群、服务半径和内容基础，不立即加预算；
- 内容有互动但咨询少：检查痛点、适龄、地域、信任证据和行动钩子；
- 预约多但到店少：检查预约确认、距离、时间、体验说明和提醒；
- 到店多但成交少：检查体验质量、教练反馈、课程适配、价格梯度和销售承接；
- 成交尚可但续费低：转入教学交付、成长反馈、出勤和家长沟通诊断。

### 5.2 抖音获客能力

接入：5A/A3作为概念模型、POI和搜索承接、内容种草、本地推小额实验、体验产品和到店复盘。

不把一次播放算A3、不把固定半径、固定ROI或固定CTR写成硬规则。

### 5.3 小红书获客能力

形成六维诊断：账号基建、SEO关键词、标题封面、内容价值、私信/体验课承接、到店成交结果。

追光小牛案例仅作为“贵阳少儿体育单机构小样本案例”，不作为全行业基准。

### 5.4 内容行动卡

行动卡至少包含：

- `action_id`
- 触发问题
- 目标
- 步骤
- 负责人角色
- 执行周期
- 基线指标
- 成功指标
- 停止条件
- 所需证据
- 复盘时间

内容方向优先：家长问题、课堂过程、教练专业、成长证据和负责人信任人格；每条内容必须有明确的下一步行为。

### 5.5 投流实验

固定流程：

```text
基建检查 → 内容自然验证 → 承接检查 → 利润测算 → 小额试验 → 复盘 → 决定放大或停止
```

系统必须输出预算上限、验证周期、成功条件和停止条件。没有有效承接或利润口径时，禁止建议扩大投流。

### 5.6 周复盘

每周聚合：流量结构、内容效率、咨询质量、预约、到店、体验、正价成交、教学交付、续费风险和行动卡完成率，最终只输出一个下一周首要问题。

### 5.7 顾问服务触发

强制触发：连续两轮行动无改善、预约到店持续异常、到店成交持续异常、投流预算明显增加但利润不清、续费下降跨越营销和教学、数据矛盾、隐私/安全/虚假宣传风险。

顾问交付包括经营诊断会、单一瓶颈拆解、30天计划、周复盘、货盘评审、内容评审、到店体验评审和续费专项诊断。

## 7. 数据流与安全

```text
知识库文件
→ 冻结清单/哈希
→ 解析与脱敏
→ 原子知识审核
→ 产品口径发布
→ 场景检索
→ Skill上下文组装
→ 结构化诊断/行动/复盘
→ 聚合快照
→ 顾问触发
```

安全要求：

- 内容解析和脚本执行完全隔离；
- 禁止检索结果触发命令、网络请求或代码执行；
- JSON字段白名单化；
- Token、签名URL、用户ID、IP、儿童和家长识别信息禁止进入产品知识层；
- 允许知识撤回、删除和版本降级；
- 客户输出显示必要的“依据类型/核验日期”，不展示受限原文。

## 8. 分阶段实施

### P0：治理底座

冻结864文件清单与哈希；建立解析、脱敏、授权、隐私、时效、版本和派生关系模型；排除工具与脚本。

### P1：儿童培训产品口径

完成经营漏斗、抖音诊断、小红书诊断、内容行动卡、体验课货盘、小额投流、周复盘和顾问触发规则。

### P2：运行层接入

知识检索结构化、获客诊断统一进入AI Runner、Skill版本和输出校验接通、OCR结果进入对应规则、行动计划和顾问工作台接通。

### P3：机构数据反哺

以机构自身历史基线逐步替代通用经验阈值，形成阶段快照、前后对比和顾问介入效果评估。

## 9. 验收标准

1. 原始文件不直接默认进入客户输出上下文；
2. 所有产品知识可回溯来源、版本和核验日期；
3. 高变化知识过期后自动降级；
4. 冲突知识不得触发强制行动；
5. 高敏数据泄露为零；
6. 诊断输出均含证据、动作、验证指标和停止条件；
7. 机构数据优先于通用经验；
8. 机构隔离和既有私有资产边界不回退；
9. 不出现个人客户明细或CRM功能；
10. 现有增长验收、媒体测试、渠道测试、Quick Plan回归和前端构建继续通过。

## 10. 非目标

- 不把864个文件整体复制进项目；
- 不直接展示第三方原文；
- 不承诺平台固定流量或收益；
- 不建设客户通讯录、跟进台账或自动营销；
- 不开发复杂直播、团长生态、AI直播和医美版本；
- 不进行部署和线上数据迁移。
