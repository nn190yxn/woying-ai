# 我赢AI项目规则

1. 本项目唯一工作根目录为 `E:\程序开发\我赢AI\woying-ai`。
2. 所有源代码、项目文档、调研材料、设计稿、实施计划、测试产物和交付文件必须保存在该根目录内，不得散落到 `E:\程序开发\我赢AI` 或其他目录。
3. 项目第一阶段唯一核心客户为儿童素质类培训机构，优先从少儿体育培训的真实业务、案例和资源开始验证。
4. 第一阶段核心商业模式为“软件 + 陪跑服务”；产品必须围绕获客、执行、线索、到店、成交和续费结果设计，不以工具数量作为成功指标。
5. 医美行业仅作为后续候选方向；儿童素质培训尚未跑通前，不并行开发医美行业版本。
6. 所有项目README和交付文档标注作者为 Monkeycode，并持续更新现有文档，不重复创建同类文档。
